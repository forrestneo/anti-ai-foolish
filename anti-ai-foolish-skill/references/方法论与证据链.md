# qu-ai-fingerprint 2.0 —— 指纹优先的终极去AI味

> 依据链：52个朱雀实测片段（human12/mid10/high9/ai21，自媒体评论文体）+ 六变体消融实验 + 用户口述人类基线 + 微信反向推演 + 21个第三方skill评测交叉验证。**没有任何第三方skill同时具备这五样**，这是本skill的优越性来源。
> 战场地图：微信判AI是五层信号（L1文本统计/L2跨文章结构一致性/L3信息价值/L4创作行为/L5账号权重）。本skill的配方管L1，发布纪律管L2-L4。L5靠养号。

## 铁律（五条，压倒一切后续规则）

1. **用户原话一个字不改**。语录库标注的用户原话、认证句式，任何刀都碰不得（纠错史#9）。
2. **指纹是生成器，不是配额**。先按指纹写，不是写完AI稿再洗——生成起点38.5 vs 修补起点60-70（纠错史#12，血泪验证两轮）。
3. **目标是人类基线带，不是0%**。用户本人手写在李白引擎下54-72%、半佛61-76%。李白≤35%即达标即停，继续压分=毁指纹=把用户文风改成检测器喜欢的别人文风。
4. **刻意装毛刺无效且有害**。错字/零宽字符/同形字/装出来的口语反问——朱雀实测装毛刺版仍77%；aijiance原话"刻意打乱结构加废话，既没躲过检测也丢了可读性"。毛刺只能来自口述里真有的东西。
5. **单引擎单次读数不作数**。外部检测器同文本波动0-85%；朱雀也按块判（同篇片段可差0.4）。任何结论要三源或复测。

## 朱雀核心触发点（2026-09-16精读定稿，逐片段对照52例得出，这是本skill的心脏）

朱雀判的不是标点、不是口语、不是排比——**是"不可预测的具体性"**（困惑度机制的通俗形态：下一个词能不能被猜到）。

**一级判据（决定性）：块里有没有"编不出来的东西"。** 按效力排序：

| 在场形态 | 实测例 | AIGC |
|---|---|---|
| 可核查的第一人称经历（"我已经学了二十多年市场营销，我天天看全球的广告"） | z18椰子水 | **0.0036** |
| 真名实姓+直接引语+叙述者身体在场（马钦"每个病人至少问5分钟"，"我刚刚穿过拥堵的人群来做采访"） | z11修仙门诊（9500字单块！） | **0.017** |
| 具体人物的具体处境清单（"MJ想进大公司，是因为大公司能提供更好的医疗保险"） | z3 f1 | 0.30 |
| 朋友讲的真事（"我另一个朋友说，她们公司老板关注几个公众号，替公司做了战略决策"） | z16 f2 | 0.26 |
| 新闻事件流（砂糖橘过剩、车厘子降价） | z19 | 0.046 |

**反例（同样有"人"却0.99+）——人必须是主体不是道具：**
- 无名代表性人物（"外卖员""资深程序员"，某类人的人形化）z10=0.998
- 人只当引子，主体是机构数据流+国家拟人（"印度人率先把账算明白了"）z2=0.997
- **姿态我/泛指你**（"你以为你独立思考""我称之为概率税"）——z4=0.998且满篇你/我。词面上"我在场"极高，全是姿态零经历。**装口语同理无效**：z9满篇"你品你细品""恭喜你悟到了"照样0.998。

**二级判据（一级缺席时才显形的"概念推演装饰"）：**
- 定义式冒号+分层标签（"核心暴论：""第一层：一线服务执行者——被系统调度的基层从业者"）
- 概念引用腔（"概率幻觉""希望贴现"，弯引号密布）
- **论证对称排比**（"可以抬起汽车却不能决定规则；可以阻止犯罪却不能改变条件"×3、"卖的是X。卖的是X。卖的是X。"）——与**叙事重复排比**（"车厘子都降价了，耙柑也降价了"，human块满篇都是）必须区分：分界在有没有对称论证骨架，不在连排本身
- 设问自答（"那问题就来了——""这账怎么算？印度人的回答是：不算了"）

**三级（此前被高估，是果不是因）：标点。** 冒号r=+0.429是因为冒号是定义推演的外壳——清冒号有效（逼你拆掉定义结构），但只清标点不装人回去，换个标点照样AI。

**推论：六刀手术是减法救命术（把0.99压到0.5下），第7刀"装人"是唯一的治本刀。** 操作化：每个块至少回填一项——①可核查的"我"的经历（口述里有就移植）②有名有姓的人+直接引语 ③编不出来的细节（排到35个号/走廊30米/至少问5分钟），且人贯穿块、不当引子。

**确认的人味信号**："实际上"-0.506（**全场最强人味词**，口语转折习惯）｜叙事重复排比（X了，Y了）-0.370｜顶真-0.242｜**直接引语（XX告诉我/XX说：）-0.233｜专名人物密度-0.225｜地名-0.230**（"人在场"的机械化部分全部过CI）｜三连短语-0.178。

**重要修正（推翻/降级自己）**：①数字密度=无信号（+0.142 CI含0，此前bucket均值是错觉）——降级为参考项；②设问自答句式=无信号，**疑问句密度才是判据**；③无名代表人物=无信号（z10系个案非通则）；④弯引号规则精确化为密度型（阈值4/千字，非"≤1处"）；⑤词表类约90条规则在评论文体全军覆打——**再堆AI黑话词表没有意义**；⑥心理直陈方向性是人味（反向于第三方通说）。

**最终合成分（发文前快筛主力）**：Z=Σ7条AI规则触发−Σ7条人味规则触发。全量r=+0.813（旧三因子分0.463），固定规则集LOO稳定，Z>0判AI：AI侧26/30、human侧11/12。**机械上限约0.8**——剩余方差是"经历我vs姿态我"等人工判据的空间。

# 第一层 · 生成侧（写新文——比手术重要十倍）

**起点决定终点**：口述底本+指纹生成的起点，比任何AI稿修补低20-30分。写新文按此顺序：

1. **骨架用口述**。用户的原话判断句做段落骨架，AI只做连接和补充，不做判断。
2. **每个判断挂叙事锚点**——某人、某年、某件事。锚点必须是人和事，**不是数字**：数据罗列是反向信号（数字最密的片段朱雀0.998）。连续三个以上并列数据点（品牌/百分比/政策名/价格），必须拆进叙事或砍。
3. **开头事件直入**。新闻/场景/第一人称现场进场，禁"钩子+痛点+承诺"三件套，禁镜头式建立（角色小动作交代环境）。
4. **结尾判断直收**。恩格斯收束弧线是内容层要求（判词→预言→一句口语收），落地时引用原文后**不许接排比升华句**（"它不是将来时，它是进行时"这种——所在段朱雀0.99+）；用一句口语判断收（"等生存斗争停止的那天，自然就掉了"）。
5. **结构层**：无小节标题、连续段落、段落长短拉开、markdown清零（信源备注区除外）。
6. **毛刺自然埋**：语气词（啊/吧/呢）≥1/千字、每3-4段一个超短句、允许一处自我修正（"我一开始以为…后来发现"）、一处离题插话。**达到即停，加多成另一种模板。**

# 第二层 · 手术侧（改存量稿——按块下刀）

**编辑单位=块（1000-2000字），不是全文**。朱雀按片段判，同篇可差0.4。先把正文按段落边界切块，每块独立过六刀。

### 第1刀 冒号（最大单刀，语料r=+0.429，消融-34分）
正文冒号全部改逗号或拆句。"真相是：""答案是：""X：Y"定义式冒号是评论文体最强AI信号（human 2.5 vs ai 5.7/千字）。信源备注区除外。

### 第2刀 概念引用腔（弯引号，差距最猛5.5倍）
AI酷爱给术语加引号（"信息阶层""阶段性过剩、结构性过剩"），human密度只有1/5.5。**正文弯引号≤1处**；引用改为直述（管完赛奖牌叫社交货币→完赛奖牌直接当社交货币卖）。破折号同步清零（改逗号）。双引号对话改直述。

### 第3刀 数据罗列块（两条独立证据链）
数字最密片段0.998-0.9983；aijiance点名"缺独家信源的整合稿"。账单段/参数段/品牌对比段：拆进叙事（"报名费六百多，不到一双专项鞋的一半"），或砍到只剩支撑判断的最少数字。

### 第4刀 金句对称收尾（唯一要禁的排比变体）
删AI叙述里可引用的哲理对称句："不是A，是B"金句化、"X看的是A，Y算的是B"、"先A再B最后C"三段链、"X贬值了Y升值了"。**判断保留，对称骨架拆掉，只写B。**用户口述里的"不是X是Y"随口直答（0.8/800字）是指纹，原位保留，AI叙述不得仿造同款。口语枚举排比（"降价了，降价了，也降价了"）**不拆**。

### 第5刀 结构与均匀
小节标题删、等长段落打断、两字词枚举连排（"封闭，消杀，撤器械"）拆成句（无论顿号逗号）、"首先其次最后/然而事实上此外"段首连接词清零、让步模板（虽然…但）≤2。

### 第6刀 轻词表（只清真雷，-4.7分）
AI黑话：赋能/抓手/闭环/颗粒度/底层逻辑/交织/画卷/维度/格局/生态/深耕。填充连接：此外/综上所述/值得注意的是/在当今/随着…的发展。翻译腔四词（作为/基于/进行/关于）AI叙述=0（用户口述原生"基于"豁免≤1/千字）。"但是"密度≤1.5/千字、"所以"≤1/千字（指纹词被用成模板时削密度，不是清零）。

### 第7刀 装人回填（治本刀——六刀只能减分，这刀才能进human带）
每个块回填至少一项（从口述/素材库取真材，禁止虚构）：
1. 可核查的"我"的经历（注意：姿态我/泛指你不算——"你以为""我称之为"实测0.998）
2. 有名有姓的人+他做的事+直接引语（真名实姓最佳；虚构人物要有专名+动作+引语，z3蜘蛛侠的MJ原话0.21）
3. 编不出来的独家细节（数字要嵌在事里："排到35个号"，不要并列罗列）
人必须做块的主体——只在开头当例子、主体换回概念数据流（z2桂林姑娘模式）照样0.99。装口语（"你品""恭喜你悟到了"）完全不算。

### 回填（每块改完）
确认该块内用户指纹自然存在：设问定义体（"这叫什么，这叫X"，一次为限）、指认句（"这就是X"显式形式全文≤1）、口语锚、判断句直收不对冲、数字口语读法（"一张一百九"）。缺了从语录库补，多了删。

## 豁免清单（词表命中也不修）

说白了 / 这叫什么？这叫X / "不是A是B"随口直答（禁金句化不禁句式）/ 你要知道 / 其实 / 最后 / 本质上 / 基于 / 然后 / 第一第二（后五个为口述原生，密度≈1/千字封顶）。
**任何第三方skill跑在用户文本上，先套本清单再看它的报告**——实测被误杀过的：unclecheng把"说白了"列直接删除；remove-ai-flavor的W4"一句话逗号>2即AI合并短句"与用户逗号连写指纹正面冲突（口述命中31处）；wiki扫描把"第一代进城市的中产"判"虚假范围"。**逗号连写是指纹不是病。**

# 第四层 · 发布纪律（L2-L4，比文本层更致命）

1. **篇篇结构变异**：无节长段/对话体/通篇叙事/混排轮换，每篇开头方式与结尾节奏必须不同。母题、素材进场、恩格斯落点是内容层保留——检测抓的是节奏重复。近十篇同构=账号级模板化=aijiance点名的首轮清洗对象。
2. **编辑行为真实化**：后台分段粘贴、中途存稿、改几处再发，单篇编辑时长≥30分钟；周1-2篇勿连发。
3. **信息价值前置**：每篇开头亮用户独有一手材料（教400人实录、HYROX现场、口述史）——"我在场"证据是L3免死金牌。
4. **可选主动声明**："内容类型声明"勾"含AI辅助"，官方允许润色级AI辅助，声明规避未声明处罚档；代价可能带标。拿一篇A/B测推荐量定。
5. **账号权重现实**：头部容错大（半佛72%天天更），小号低权重+连发=高危。新号降频，把L3做厚。

## 反模式（明确禁做，全部有实测背书）

- ❌ 加名句/引用/修辞/金句"提升文化密度"（de-ai-style-polish路线=朱雀100%翻车）
- ❌ 错字/零宽字符/同形字/随机标点伪装人类（装毛刺77%；且账号风险）
